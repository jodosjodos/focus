Read `docs/FOCUS-development-plan.md` to find the full phase list and the current phase (check `CLAUDE.md`'s "Current status" line for which phase is marked active). Compare that phase's Definition of Done checklist against the actual code in `apps/mobile` and `apps/backend`.

Report clearly:
- What's done
- What's missing
- What to build next to close out this phase

If everything in the Definition of Done is genuinely met, say so plainly and ask whether to update `CLAUDE.md`'s "Current status" line and move to the next phase — don't update it unprompted.
